# SMTPUTF8 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use bitranox:process-agents-subagent-driven-development (recommended) or bitranox:process-plan-executor to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `send()` and the CLI deliver to and from addresses with non-ASCII local parts and domains
over RFC 6531 SMTPUTF8, while all-ASCII mail stays byte-identical.

**Architecture:** One predicate, `needs_smtputf8(sender, recipient)` in `_validation.py`, decides
per message. Validation NFC-normalises and accepts internationalised addresses; composition folds
a non-ASCII From/To with `email.policy.SMTPUTF8`; the transport adds `SMTPUTF8 BODY=8BITMIME` to
MAIL FROM, and a relay without the extension raises `SMTPUTF8NotSupportedError`, counted as a
refusal of that message (next host), not of the host.

**Tech Stack:** Python 3.10-3.15, stdlib `smtplib` / `email` / `unicodedata`, pytest, aiosmtpd
(`enable_SMTPUTF8=`), bmk (`make test`).

Design: `docs/plans/2026-10-13-smtputf8-design.md` (owner-agreed).

## Global Constraints

- All-ASCII mail is unchanged byte for byte: headers, MAIL FROM (no options), messages, refusals.
- Every input the old version refused keeps its exception type, exit code AND message unless it is
  now accepted; ASCII length messages keep the word "characters".
- No new runtime dependency; no punycode/IDNA conversion.
- Every new or changed function: Google docstring with Args, Returns, Raises (when it raises) and a
  runnable doctest under Examples. `from __future__ import annotations` stays first.
- Never write a backslash-u escape into a tool argument: build invisible characters with `chr(0x...)`
  in code (literal readable letters such as `ä`, `ü`, `中国` are fine in source).
- Tests: no patching of the package's own code; real aiosmtpd for the wire, `RecordingTransport` for
  orchestration. Gate: `make test` (never a hand-picked subset); run it in the worktree only.
- Layer contract: `_transport` and `_compose` may import `_validation`; `_validation` imports only
  `_common` and `errors`.
- No Claude/AI attribution in commits. Commit messages via `git commit -F <file>`.

```python
def address_length_problem(address: str) -> str | None:
    """Describe how address exceeds the RFC 5321 lengths, or return None.

    RFC 5321 section 4.5.3.1 allows 64 octets before the `@` and a 256-octet
    path, which leaves 254 for the address between the angle brackets. The
    lengths are UTF-8 octets, so a non-ASCII character counts as the two to
    four it takes on the wire; the description says "characters" for an ASCII
    address (where the two are the same) and "UTF-8 octets" otherwise. It names
    the length, so a caller can report it without quoting the address.

    Args:
        address: Candidate email string.

    Returns:
        The problem as a sentence fragment, or None when both lengths fit.

    Examples:
        >>> address_length_problem("user@example.com") is None
        True
        >>> address_length_problem("a" * 65 + "@example.com")
        'the local part has 65 characters, more than the 64 RFC 5321 allows'
        >>> address_length_problem(chr(0xE4) * 33 + "@example.com")
        'the local part has 66 UTF-8 octets, more than the 64 RFC 5321 allows'
    """
    unit = "characters" if address.isascii() else "UTF-8 octets"
    local_part, at_sign, _domain = address.rpartition("@")
    local_size = _utf8_octets(local_part)
    if at_sign and local_size > _MAX_LOCAL_PART:
        return f"the local part has {local_size} {unit}, more than the {_MAX_LOCAL_PART} RFC 5321 allows"
    size = _utf8_octets(address)
    if size > _MAX_ADDRESS:
        return f"{size} {unit}, more than the {_MAX_ADDRESS} RFC 5321 allows"
    return None


def _utf8_octets(text: str) -> int:
    """Return how many octets text takes as UTF-8.

    A lone surrogate counts as the three octets it would take; the syntax check
    refuses it afterwards, and the length check must not raise on it first.

    Args:
        text: The text to measure.

    Returns:
        The UTF-8 length in octets.

    Examples:
        >>> _utf8_octets("abc"), _utf8_octets(chr(0xE4)), _utf8_octets(chr(0xDCFF))
        (3, 2, 3)
    """
    return len(text.encode("utf-8", "surrogatepass"))
```

def _normalise_email_address(candidate: str) -> str:
    """Trim whitespace/quotes, normalise to NFC, and lower-case the result if it is ASCII.

    Email addresses compare case-insensitively in our context, so an ASCII
    address is lower-cased for de-duplication. NFC runs first (RFC 6532 asks
    for it), so a decomposed `a` plus combining diaeresis becomes the `ä` a
    caller typed elsewhere, and a character that is canonically an ASCII letter
    (KELVIN SIGN is `K`) is then lower-cased like one. A non-ASCII address
    keeps its case: Unicode lower-casing can change the length and leave
    non-NFC text, and RFC 5321 treats the local part as case-sensitive.

    Args:
        candidate: Raw string supplied by the caller.

    Returns:
        Normalised email address (may be empty string).

    Examples:
        >>> _normalise_email_address(' "B@Example.com" ')
        'b@example.com'
        >>> _normalise_email_address("a" + chr(0x308) + "@Example.com") == chr(0xE4) + "@Example.com"
        True
    """
    trimmed = to_nfc(candidate.strip().strip('"').strip("'"))
    return trimmed.lower() if trimmed.isascii() else trimmed
```

def validate_email_address(address: str) -> None:
    """Raise when address is not a syntactically valid email address.

    Prevents avoidable SMTP failures by checking syntax early. An ASCII address
    must match `EMAIL_PATTERN`; an address holding non-ASCII characters is an
    internationalised one (RFC 6531), checked by `matches_address_syntax`. The
    lengths are UTF-8 octets (`address_length_problem`). The address is checked
    as given: `send()` normalises it to NFC first, this function does not.

    Args:
        address: Candidate email string.

    Raises:
        InvalidInputError: If address is longer than RFC 5321 allows (the
            message names the length, not the address) or does not have the
            address syntax.

    Examples:
        >>> validate_email_address("user@example.com")
        >>> validate_email_address("empf" + chr(0xE4) + "nger@m" + chr(0xFC) + "ller.de")
        >>> validate_email_address("invalid@")
        Traceback (most recent call last):
            ...
        btx_lib_mail.errors.InvalidInputError: invalid email address: 'invalid@'
    """
    require_text(address, field_name="email address")
    problem = address_length_problem(address)
    if problem is not None:
        raise InvalidInputError(f"invalid email address: {problem}")
    if not matches_address_syntax(address):
        raise InvalidInputError(f"invalid email address: {address!r}")
```

def to_nfc(address: str) -> str:
    """Return address in Unicode Normalization Form C, the form RFC 6532 asks for.

    The same visible character can be one code point or a base letter plus a
    combining mark; a relay comparing bytes treats the two as different
    mailboxes. NFC picks the composed form. An ASCII address is returned as it is.

    Args:
        address: The address as the caller gave it.

    Returns:
        The NFC form of address.

    Examples:
        >>> to_nfc("a" + chr(0x308) + "@example.com") == chr(0xE4) + "@example.com"
        True
        >>> to_nfc("User@Example.com")
        'User@Example.com'
    """
    return unicodedata.normalize("NFC", address)


def matches_address_syntax(address: str) -> bool:
    """Return whether address has the syntax of a deliverable email address.

    An ASCII address must match `EMAIL_PATTERN`, exactly as before. An address
    holding non-ASCII characters is internationalised (RFC 6531): its local part
    allows the ASCII characters `EMAIL_PATTERN` allows plus any printable
    non-ASCII character, and its domain is dot-separated labels of letters,
    digits (any script) and hyphens, ending in a label of at least two letters
    or an `xn--` label. Lengths are not checked here (`address_length_problem`).

    Args:
        address: Candidate email string.

    Returns:
        True when address has the syntax, False otherwise.

    Examples:
        >>> matches_address_syntax("user@example.com")
        True
        >>> matches_address_syntax("empf" + chr(0xE4) + "nger@example.com")
        True
        >>> matches_address_syntax("user@m" + chr(0xFC) + "ller")
        False
    """
    if address.isascii():
        return EMAIL_PATTERN.fullmatch(address) is not None
    local_part, at_sign, domain = address.rpartition("@")
    return bool(at_sign) and _is_international_local_part(local_part) and _is_international_domain(domain)


def needs_smtputf8(sender: str, recipient: str) -> bool:
    """Return whether the message from sender to recipient must travel as SMTPUTF8 (RFC 6531).

    It must when either address holds a non-ASCII character. Composition folds
    such an address as raw UTF-8 and the transport announces SMTPUTF8 for it;
    both ask this one function, so they cannot disagree.

    Args:
        sender: The envelope sender, as `send()` normalised it.
        recipient: The envelope recipient, as `send()` normalised it.

    Returns:
        True when either address holds non-ASCII, False when both are ASCII.

    Examples:
        >>> needs_smtputf8("a@example.com", "b@example.com")
        False
        >>> needs_smtputf8("a@example.com", "b@m" + chr(0xFC) + "ller.de")
        True
    """
    return not (sender.isascii() and recipient.isascii())


def _is_international_local_part(local_part: str) -> bool:
    """Return whether local_part is a non-empty internationalised local part.

    Args:
        local_part: The text before the last `@`.

    Returns:
        True when it is non-empty and every character is allowed there.

    Examples:
        >>> _is_international_local_part("empf" + chr(0xE4) + "nger"), _is_international_local_part("")
        (True, False)
    """
    return bool(local_part) and all(_is_local_part_character(character) for character in local_part)


def _is_local_part_character(character: str) -> bool:
    """Return whether character may stand in an internationalised local part.

    An ASCII character must be one `EMAIL_PATTERN` allows. A non-ASCII one must
    be printable: `str.isprintable()` is False for controls (Cc), format
    characters (Cf, which holds every bidirectional mark, override and isolate,
    and the zero-width joiner), separators (Z*, the no-break space among them),
    surrogates (Cs) and unassigned code points (Cn).

    Args:
        character: One character.

    Returns:
        True when it is allowed.

    Examples:
        >>> _is_local_part_character(chr(0xE4)), _is_local_part_character(chr(0x200E)), _is_local_part_character(" ")
        (True, False, False)
    """
    if character.isascii():
        return character in _ASCII_LOCAL_PART_CHARACTERS
    return character.isprintable()


def _is_international_domain(domain: str) -> bool:
    """Return whether domain is a dotted name of valid labels with a valid top-level label.

    Args:
        domain: The text after the last `@`.

    Returns:
        True when there are two or more labels, each valid, and the last is at
        least two letters long or an `xn--` label.

    Examples:
        >>> _is_international_domain("m" + chr(0xFC) + "ller.de"), _is_international_domain("m" + chr(0xFC) + "ller")
        (True, False)
    """
    labels = domain.split(".")
    if len(labels) < _MIN_DOMAIN_LABELS or not all(_is_domain_label(label) for label in labels):
        return False
    top = labels[-1]
    return (len(top) >= _MIN_TOP_LEVEL_LABEL and top.isalpha()) or top.lower().startswith(_ACE_PREFIX)


def _is_domain_label(label: str) -> bool:
    """Return whether label is letters, digits (any script) and inner hyphens.

    Args:
        label: One dot-separated part of a domain.

    Returns:
        True when it is non-empty, starts and ends with a letter or digit, and
        holds nothing but letters, digits and hyphens.

    Examples:
        >>> _is_domain_label("m" + chr(0xFC) + "ller"), _is_domain_label("-x"), _is_domain_label("")
        (True, False, False)
    """
    return bool(label) and not label.startswith("-") and not label.endswith("-") and all(character.isalnum() or character == "-" for character in label)
```

def envelope_header_lines(*, sender: str, subject: str, recipients: Sequence[str]) -> tuple[bytes, ...]:
    """Return each recipient's header lines (Subject, From, To, Date), CRLF-terminated, no blank line.

    Subject and From are the same for every recipient and folded once: folding
    a long non-ASCII subject costs tens of milliseconds, which per recipient
    added up to over a minute for a thousand. Each header folds on its own, so
    joining the shared lines to a recipient's own gives the same bytes as
    folding all four together.

    A From or To header whose address holds non-ASCII is folded with
    `email.policy.SMTPUTF8`, which writes the address as raw UTF-8 (RFC 6532);
    that message travels as SMTPUTF8 (`needs_smtputf8`). Every other header is
    folded with `email.policy.SMTP`, so a message whose addresses are ASCII is
    unchanged byte for byte. The subject keeps its RFC 2047 encoded-words, which
    are valid in both kinds of message.

    Args:
        sender: The From address.
        subject: The message subject.
        recipients: The To addresses, one header block each.

    Returns:
        One block of CRLF-terminated header lines per recipient, in order,
        with no trailing blank line.

    Examples:
        >>> [block] = envelope_header_lines(sender="a@example.com", subject="Hi", recipients=["b@m" + chr(0xFC) + "ller.de"])
        >>> b"To: b@m" + chr(0xFC).encode() + b"ller.de" in block
        True
    """
    shared_lines = _header_lines(_single_header("Subject", subject)) + _address_header_lines("From", sender)
    date = formatdate(localtime=True)
    return tuple(shared_lines + _recipient_header_lines(recipient, date) for recipient in recipients)


def _recipient_header_lines(recipient: str, date: str) -> bytes:
    """Return one recipient's own header lines (To, Date).

    Args:
        recipient: The To address.
        date: The Date header value shared by the whole call.

    Returns:
        The CRLF-terminated To and Date lines.

    Examples:
        >>> _recipient_header_lines("b@example.com", "Tue, 13 Oct 2026 10:00:00 +0200")
        b'To: b@example.com\\r\\nDate: Tue, 13 Oct 2026 10:00:00 +0200\\r\\n'
    """
    return _address_header_lines("To", recipient) + _header_lines(_single_header("Date", date))


def _address_header_lines(name: str, address: str) -> bytes:
    """Return one address header, folded as raw UTF-8 when the address holds non-ASCII.

    Args:
        name: The header name (`From` or `To`).
        address: The bare address.

    Returns:
        The CRLF-terminated header line(s).

    Examples:
        >>> _address_header_lines("To", "b@example.com")
        b'To: b@example.com\\r\\n'
        >>> _address_header_lines("To", "b@m" + chr(0xFC) + "ller.de") == ("To: b@m" + chr(0xFC) + "ller.de\\r\\n").encode()
        True
    """
    return _header_lines(_single_header(name, address), utf8=not address.isascii())


def _single_header(name: str, value: str) -> EmailMessage:
    """Return a message holding one header, so it can be folded on its own.

    Args:
        name: The header name.
        value: The header value.

    Returns:
        A headers-only `EmailMessage`.

    Examples:
        >>> _single_header("Subject", "Hi")["Subject"]
        'Hi'
    """
    message = EmailMessage()
    message[name] = value
    return message
```

and `_header_lines` gains the policy switch (keep its callers `_header_block` etc. on the default):

```python
def _header_lines(message: EmailMessage, *, utf8: bool = False) -> bytes:
    """Serialise a message's headers to CRLF bytes, without the terminating blank line.

    Args:
        message: The message whose headers are serialised.
        utf8: Fold with `email.policy.SMTPUTF8` (raw UTF-8, RFC 6532) instead
            of `email.policy.SMTP` (RFC 2047 encoded-words).

    Returns:
        The CRLF-terminated header lines, with no trailing blank line.

    Examples:
        >>> _header_lines(_single_header("To", "b@example.com"))
        b'To: b@example.com\\r\\n'
    """
    policy = email_policy.SMTPUTF8 if utf8 else email_policy.SMTP
    out = bytearray()
    for name, value in message.items():
        out += policy.fold_binary(name, value)
    return bytes(out)
```

```python
def _open_envelope(smtp_connection: smtplib.SMTP, sender: str, recipient: str) -> None:
    """Issue MAIL FROM / RCPT TO, raising on rejection (shared by DATA and BDAT).

    A message with a non-ASCII address announces SMTPUTF8 and BODY=8BITMIME on
    MAIL FROM (`_mail_options`); smtplib then sends both commands as UTF-8.

    Args:
        smtp_connection: The SMTP connection to issue the commands on.
        sender: Envelope sender address.
        recipient: Envelope recipient address.

    Raises:
        SMTPUTF8NotSupportedError: The message needs SMTPUTF8 and the relay does not offer it.
        smtplib.SMTPSenderRefused: The server rejected MAIL FROM.
        smtplib.SMTPRecipientsRefused: The server rejected RCPT TO.
    """
    code, resp = smtp_connection.mail(sender, _mail_options(smtp_connection, sender, recipient))
    if code != _SMTP_OK:
        raise smtplib.SMTPSenderRefused(code, resp, sender)
    code, resp = smtp_connection.rcpt(recipient)
    if code not in (_SMTP_OK, _SMTP_WILL_FORWARD):
        raise smtplib.SMTPRecipientsRefused({recipient: (code, resp)})


def _mail_options(smtp_connection: smtplib.SMTP, sender: str, recipient: str) -> tuple[str, ...]:
    """Return the MAIL FROM parameters this message needs, refusing a relay that cannot take it.

    smtplib checks the advertisement only in an ESMTP session; after a HELO
    fallback it would send the address in its ASCII command encoding and raise
    `UnicodeEncodeError`. So the advertisement is checked here, for both.

    Args:
        smtp_connection: The session, after EHLO or HELO.
        sender: Envelope sender address.
        recipient: Envelope recipient address.

    Returns:
        `("SMTPUTF8", "BODY=8BITMIME")` when either address holds non-ASCII, else `()`.

    Raises:
        SMTPUTF8NotSupportedError: The message needs SMTPUTF8 and the relay does not offer it.

    Examples:
        >>> _mail_options(smtplib.SMTP(), "a@example.com", "b@example.com")
        ()
    """
    if not needs_smtputf8(sender, recipient):
        return ()
    if not smtp_connection.has_extn("smtputf8"):
        raise SMTPUTF8NotSupportedError("the relay does not offer SMTPUTF8, which a non-ASCII address needs")
    return _SMTPUTF8_MAIL_OPTIONS
```
